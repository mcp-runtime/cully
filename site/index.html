01 / THE LOOP

Observe. Understand.
Remember. Advise. Improve.

Coding agents are powerful, but each one mostly sees the task in front of it. Cully keeps track of the broader development process around them.

01

Observe

The Cully terminal and agent hooks turn tool calls into small events: an edit, a check, a search, a memory call.

02

Understand

A private session journal shows what happened: the same test failing three times, edits nobody checked.

03

Remember

Decisions, attempts, results and next steps are saved through MCP and found again by meaning.

04

Advise

A second pair of eyes for your coding agent. It warns about loops, context pressure and missing verification.

05

Improve

Cully notices how you usually ship in a project, such as running checks after editing, and says when a session skips it.

06

Across agents

Start in Claude Code, continue in Codex, finish in Cursor. The record belongs to the project, not to one agent.

TEAM WORKSPACE

The work continues.
The context comes with it.

Keep the outcome, ownership and evidence connected when work moves between teammates and coding agents.

01

Know what needs attention

A project board and inbox show active tasks, blockers and waiting reviews. Claims keep two people from silently taking the same task.

02

Pick up where they stopped

Continue from a checkpoint with decisions, the branch, artifact links and the next action. Start your preferred agent and keep the task connected.

03

Review, then reuse

A reviewer checks the criteria and evidence at the submitted revision. Authors choose which lessons to publish; maintainers adopt guidance for later work.

Team workflows use CLI or MCP with signed-in project members. Agent launch is manual; submitted checks are labeled as reported evidence. Private notes and local journals stay separate.

04 / THE TERMINAL

One terminal.
Every agent.

Cully is not another terminal emulator to learn. It is the observation surface that lets it understand what any agent is doing, using the agent exactly as before.

01

Same wrapper everywhere

cully run claude, codex, cursor or any executable on your PATH gets the same health bar and advisor panel.

02

A health bar you can trust

Agent, project and branch, session time, context, loops and unchecked edits. Segments with no data are left out.

03

An advisor you can click

Click the panel or press Ctrl+] to open every suggestion. Nothing is applied until you approve a preview.

Supported on macOS and Linux. Cursor support wraps the cursor-agent CLI. Cully's tool events come from each agent's hooks, so an agent without hooks gets the health bar and Git state but not loop detection or replay.

PRIVACY

Your conversations aren't Cully's database.

The local session journal keeps the time, the kind of tool, whether it passed, project-relative file paths and the program of a command. It never keeps prompts, file contents, command arguments or tool output, and you can turn off path recording. Project memory holds only the short summary your agent chooses to save.
